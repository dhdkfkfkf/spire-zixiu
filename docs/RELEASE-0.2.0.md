# 0.2.0 — 牌池补全与九字真言

## 修掉的问题

- **拆字吞牌**：`CardComponents.createComponent` 只认 火 / 木 / 口，其余 7 个部件返回 `null`，
  `addToHand(null)` 直接 return，原牌照样进消耗堆。拆 `大` 什么都不给、拆 `因` 只剩一个 `口`，都是这个原因。
- **54 条配方不可达**：只有部件全在 {火, 木, 口} 里的配方能合出来，67 条 PLAYABLE 里实际只有 13 条可达，
  已实现的 48 张牌里 37 张是死内容（`天` `明` `晶` `淡` `灶` …）。
- **1/4 空抽**：`吉` / `墨汁` / `厚林` 的部件池含 `人`，抽到就白给。

## 新增

**部件牌 7 张**：人 / 月 / 土 / 一 / 水 / 山 / 日，10 个部件全部可造。

| 部件 | 效果 |
|---|---|
| 人 | 造成 1 伤害 2 次 |
| 月 | 获得 1 格挡，治疗 1 |
| 土 | 获得 3 格挡 |
| 一 | 抽 1 |
| 水 | 治疗 2 |
| 山 | 给予 1 层虚弱 |
| 日 | 施加 1 层曝光 |

**成品牌 19 张**：从 囚 休 伙 仕 回 吕 本 末 未 吐 朋 出 且 合 坐 唱 查 胆。

- 焚：从 / 伙 / 末 / 出 / 胆
- 润：囚 / 休 / 仕 / 本 / 吐 / 朋 / 坐
- 照：回 / 吕 / 未 / 唱 / 查
- 通用：且 / 合

新能力牌：
- `合`：每合出一个字，抽 1 并获得 1 格挡（每回合 2 次）。
- `朋`：每拆解一张牌，抽 1（每回合 2 次）。
- `本`：回合开始时获得 3 格挡。

## 九字真言（0.2.0 新增）

临 兵 斗 者 皆 阵 列 前 行，九个字各是一件 SPECIAL 遗物，集齐后获得「真言」：
每打出一张牌，所有敌人获得 1 层虚弱与 1 层易伤。

| 字 | 效果 |
|---|---|
| 临 | 战斗开始抽 1 |
| 兵 | 每打出一张攻击牌得 2 格挡 |
| 斗 | 每回合第奇数次拆解抽 2 |
| 者 | 每合出一个字得 5 格挡 |
| 皆 | 每拆一张治疗 3 |
| 阵 | 格挡不衰减 + 每回合结束 6 格挡 |
| 列 | 手牌上限 +2 |
| 前 | 每回合第偶数次打出部件牌抽 1 |
| 行 | 回合结束若合过也拆过，下回合 +5 敏捷 |

获取：事件「九字碑」（每局最多两次）、遗物「残碑」（每次遗物奖励补一个缺失的字）。
隔离开关在模组设置面板，默认只进字修角色池，关闭后改为共享池（重启生效）。
