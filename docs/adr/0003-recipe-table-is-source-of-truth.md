# 配方表是拼合的唯一真相来源

拼合不靠「部件多重集推导」，而是查一张手写的配方表；表里没有的组合不可拼合。原因是汉字结构本身不自洽：`本`/`末`/`未` 同为 {木, 一}，`回`/`吕` 同为 {口, 口}，`呆`/`杏`/`困`/`束` 同为 {口, 木}——任何数学规则都会撞车。

**不做字序**：拼合是无序多重集，先后选择不改变结果。

**撞车消解**：一个多重集对应多个字时，拼合前弹出**选字面板**，由玩家挑一个字成型。于是 {口, 木} 可以出 呆、杏、困、束 四选一，{木, 一} 出 本、末、未 三选一，{口, 口} 出 回、吕 二选一。

只列**有用结果**（可打出，或可作字胚继续拼）。废字与无配方组合不高亮、不进面板、不可拼合。

**拆解与拼合对称**：拆解与拼合都是免费、不限次数的基础动作。右键手牌中的任意成品牌即可拆解，按配方表还原出全部部件；原牌进入**消耗堆**，本场战斗不再出现。

**墨迹未干**：本回合合出来的成品牌，当回合不能拆解。没有这一条，`拆 呆 → 合 杏 → 拆 杏 → 合 呆` 就是一个免费的无限循环，任何「拆解时触发」的效果都会变成无限资源。

拆解没有元数限制，所以 `品`(3 口)、`淼`(3 水)、`合`(人+一+口) 虽然拼不出来，却拆得开。`永` 是独体字，成为全池唯一不可拆的牌。

「拆」是除「合」之外的第二条投资线：部分卡牌在拆解时触发额外效果。
