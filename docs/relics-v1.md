# v1 遗物与药水

角色身份：**箓生**——似乎很神秘的落魄书生，解箓成箓之间打架。焚 = 烧书取火，润 = 护卷抄书，照 = 校勘照字。

## 遗物（7）

| 稀有度 | 名 | 效果 |
|---|---|---|
| 起始 | 秃笔 | 战斗开始时，从 3 张随机部件牌中选择 1 张加入手牌。 |
| 普通 | 残砚 | 每场战斗第一次合字后，抽 1 张牌。 |
| 普通 | 火折子 | 每回合第一次施加灼烧时，额外施加 1 层。 |
| 普通 | 旧书签 | 回合开始时，若手牌中没有部件牌，将 1 张随机部件牌加入手牌。 |
| 罕见 | 书匣 | 每当你拆解一张牌，将 1 张随机部件牌加入手牌（每回合上限 1）。 |
| 罕见 | 朱笔 | 每当你合出一个成品牌，抽 1 张牌（每回合上限 1）。 |
| 稀有 | 活字盘 | 每回合开始时，将 1 张随机部件牌加入手牌。 |

## 九字真言（9 + 1，SPECIAL，不进遗物池）

「临兵斗者皆阵列前行」，一个字一件遗物。只能通过「九字碑」事件或「残碑」遗物获得，
不会出现在常规遗物奖励里。集齐九字后获得**真言**：每打出一张牌，所有敌人获得 1 层虚弱与 1 层易伤。

| 字 | 效果 |
|---|---|
| 临 | 战斗开始时，抽 1 张牌。 |
| 兵 | 每当你打出一张攻击牌，获得 2 点格挡。 |
| 斗 | 每回合第奇数次拆解时，抽 2 张牌。 |
| 者 | 每当你合出一个字，获得 5 点格挡。 |
| 皆 | 每当你拆解一张牌，治疗 3 点生命。 |
| 阵 | 格挡不会在回合开始时消失；每回合结束时获得 6 点格挡。 |
| 列 | 手牌上限 +2。 |
| 前 | 每回合第偶数次打出部件牌时，抽 1 张牌。 |
| 行 | 回合结束时若本回合既合过字又拆过牌，下回合获得 5 点敏捷，下回合结束时失去。 |

获取：

- **残碑**（稀有，字修专属）：每场战斗的遗物奖励里，额外出现一个你没有的九字。
  做法与圣主「寻符器」一致——在 `CombatRewardScreen.setupItemReward` 之后往 `room.rewards` 插一条 `RewardItem`。
- **九字碑**（事件，每局最多两次，集齐后不再出现）：拓下一个字／以 8 点生命换两个字／离开。

隔离：默认只进字修的角色池（`addRelicToCustomPool`），普通角色看不到。模组设置面板里有开关，
关闭后九个字改为 RARE + 共享池，任何角色都可能掉到（需要重启游戏生效）。

## 药水（3）

| 名 | 效果 |
|---|---|
| 墨汁 | 将 2 张随机部件牌加入手牌。 |
| 朱砂 | 对所有敌人施加 3 灼烧。 |
| 拓片 | 复制手牌中一张成品牌（复制品本场不可拆解）。 |

## 事件（2，草案）

**错字**：你在碑上看到一个写错的字。拆开它（获得 2 张随机部件牌）／照抄（获得 1 张随机成品牌，失去 5 生命）／离开。

**残卷**：一册被烧掉一半的书。抄录（获得 1 张稀有牌，最大生命 −3）／修补（获得 2 张部件牌，治疗 10）／烧掉（获得 1 瓶朱砂）。
