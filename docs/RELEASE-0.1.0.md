# 0.1.0 — 首个可玩版本

字修是《杀戮尖塔》的角色 Mod：10 个部件牌（人 口 木 月 土 一 水 火 山 日）既是 0 费卡牌，也是拼字材料。合两张拼出一个字，拆一张字又变回部件。

## 下载

- `zixiu.jar`
- 依赖：ModTheSpire 3.30.0+、BaseMod、StSLib
- 适配游戏版本：12-18-2022（最终版），Java 8

## 这一版有什么

- **合**：选两张部件牌拼字，免费、不限次数；`口+木` 这类多结果会弹出选字面板。
- **拆**：成品牌拆回部件，原牌进消耗堆；本回合合出来的字当回合不能拆。
- **85 字配方表**：含字胚 `圭`（拼得出、打不出，但能继续拼）、废字与无配方字。
- **三条脉 + 53 张牌**：焚（灼烧不递减 + 引爆）、润（格挡/治疗/格挡保留）、照（消耗型曝光 + 倍增）。
- **7 遗物 / 3 药水 / 2 事件**：起始遗物「秃笔」是战斗开始的三选一部件。

## 已知不足

- 全部卡牌共用一张纯色占位卡图，正式美术尚未接入。
- 卡框为纯色圆角卡，没有原版边框纹理。
- 数值与平衡未经实战验证。
